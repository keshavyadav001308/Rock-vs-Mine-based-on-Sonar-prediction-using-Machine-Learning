 Rock vs Mine Prediction using Machine Learning

Project Description
This project focuses on classifying underwater objects as **Rock** or **Mine** using **sonar signal data** and a **Random Forest machine learning model**. The objective is to build a reliable prediction system by analyzing sonar frequency features and applying supervised learning techniques.

 Objectives
- Classify sonar signals into Rock or Mine categories  
- Apply Random Forest for accurate prediction  
- Perform data preprocessing and feature analysis  
- Evaluate model performance using standard metrics  


 Dataset Information
- Dataset: Sonar Dataset  
- Source: UCI Machine Learning Repository  
- Features: 60 numerical sonar frequency attributes  
- Target variable: Rock (R) or Mine (M)

 Technologies Used
- **Python**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Matplotlib / Seaborn**
- ** Google Colab**

 Methodology
1. Data loading and preprocessing  
2. Feature scaling and train-test split  
3. Model training using Random Forest  
4. Prediction and evaluation  
5. Performance comparison and tuning  


Model Evaluation
- Accuracy Score
